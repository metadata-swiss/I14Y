# Contributing

Thank you for your interest in I14Y.

External code contributions are currently not accepted for this project.

## How to Share Feedback or Requests

If you want to report a bug, request a feature, or share an improvement idea, please open an issue here:

https://github.com/I14Y-ch/feature-requests/issues

Please include:

- A clear title and short summary
- Context and expected behavior
- Reproduction steps (for bugs)
- Screenshots or logs when relevant

## Pull Requests

At this time, we do not accept external pull requests or direct external code changes in this repository.
